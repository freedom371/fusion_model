## 1. 最终模型结构

当前 `pathology_model/model.py` 的有效执行层为：

```python
nn.Sequential(
    nn.Dropout(dropout),
    nn.Linear(1536, 64),
    nn.ReLU(inplace=True),
    nn.Linear(64, 1),
)
```

训练入口 `train.py` 中 `conf['dropout']=0.2`，并显式创建：

```python
model = PathologyOnlyModel(dropout=c['dropout']).to(device)
```

最终应统一表述为：

> 患者级 1536 维 UNI2 特征经过训练集统计量的 z-score 标准化后，依次通过 Dropout(p=0.2)、Linear(1536,64)、ReLU 和 Linear(64,1)，输出单个 logit；评估时经 sigmoid 得到复发概率。模型本体无 LayerNorm 或 BatchNorm，输出层前无第二个 Dropout。

代码中被注释的 LayerNorm、其他隐藏层和 Dropout 不执行。`PathologyOnlyModel` 构造函数默认值 0.5 也不是当前训练的生效值，训练传入的 0.2 会覆盖默认值。

总可训练参数为 98,433：第一层 98,368，输出层 65；Dropout 和 ReLU 不引入可训练参数。

依据：[模型定义](../pathology_model/model.py)、[训练入口](../pathology_model/train.py)。

## 3. z-score 的实际方案与参数来源

### 数据来源

`pathology_model/config.py` 当前配置为：

```python
LABEL_CSV = ROOT / 'data/cvs/label_l_impact100_val58_r32_t36_mv40_v3_d3_m3.csv'
DATA_PATH_DIR = ROOT / 'data/uni2_feature/jiandu'
PATH_DIM = 1536
```

每个患者读取：

```text
data/uni2_feature/jiandu/{ID}/{ID}_uni2_slide_features.npy
```

加载后执行 `squeeze(0).astype(np.float32)`，即 `(1,1536)` 转为 `(1536,)`。当前训练集 420 例、验证集 129 例、外部测试集 100 例。

### 统计与应用

`pathology_model/dataset.py` 在构建 train 数据集时，将训练患者特征堆叠为 `(420,1536)`，沿患者轴逐维计算：

```python
path_mean = arr.mean(axis=0)
path_std = arr.std(axis=0) + 1e-8
PathologyDataset._norm_stats = (path_mean, path_std)
```

mean 和 std 均为长度 1536 的 float32 向量。标准差使用 NumPy 默认 `ddof=0`，即总体标准差，再加 `1e-8`。

所有集合统一执行：

```python
z = (x - path_mean) / path_std
```

val/test 复用训练统计量，不计算自己的均值和标准差。若未先构建训练数据集，则 val/test 构建代码会读取 CSV 的 train 组特征来计算统计量，也不是在 val/test 上拟合。

训练入口按 train → val → test 顺序创建数据集。本次运行核验，在该通常路径中，三组的均值和标准差数组逐元素完全相同。

### 是否已有固定参数文件

当前统计量保存在模块级 `PathologyDataset._norm_stats` 缓存中，**现有 checkpoint 没有保存 z-score 参数**。核对当前 `best_model_seed2837.pt` 的键为：

```text
epoch
model_state_dict
val_metrics
test_metrics
```

因此，跨进程加载时会根据配置的数据重新计算，而不是从一个现有 scaler 文件读取。复现当前方案需要保持分组 CSV、特征文件、统计方法不变；不能把运行时缓存表述为已经随 checkpoint 固定保存。

本次导出的参数快照用于审阅归档，包含：

| 文件 | 内容 |
|---|---|
| `pathology_zscore_parameters_20261027.npz` | `mean`：1536 维训练均值；`std`：1536 维训练总体标准差加 1e-8；`train_ids`：拟合患者名单 |
| `pathology_zscore_parameters_20261027.json` | 拟合范围、配置来源、统计公式、输入哈希、当前模型层次、训练配置和核验结果 |

现有训练及推理代码不会自动加载本次 NPZ。本次没有修改模型代码、训练配置或 checkpoint。

参数快照读取方式：

```python
import numpy as np

params = np.load('materials/pathology_zscore_parameters_20261027.npz')
mean = params['mean']
std = params['std']  # 已包含 1e-8，不重复添加
z = (patient_features.astype(np.float32) - mean) / std
```

依据：[配置](../pathology_model/config.py)、[统计量计算与应用](../pathology_model/dataset.py)。

## 4. 标准化与模型归一化层不是同一概念

z-score 在数据加载时针对每个特征维度，使用训练人群的统计量执行；LayerNorm 则是网络内部的归一化层。最终病理模型**有输入 z-score 标准化，但没有网络内部 LayerNorm/BatchNorm**。同样，网络保留了 ReLU，不能称为“两个 Linear 连续相接、没有非线性激活”。

## 5. 验证记录

- 按训练配置创建模型，确认只有 Dropout(0.2)、Linear(1536,64)、ReLU、Linear(64,1)。
- 当前 `best_model_seed2837.pt` 可严格加载到该结构；检查点线性层参数形状分别为 `(64,1536)`、`(64,)`、`(1,64)`、`(1,)`。
- 重新读取训练集 420 例特征计算 mean/std，与训练数据集所用统计量逐元素完全一致。
- 按训练入口顺序创建 train/val/test，确认三者使用完全相同的统计量。
- 单独创建 val 时仍从 train 计算；该分支按 CSV 顺序累加，而常规训练路径按排序后的患者顺序累加，float32 求和顺序会导致很小的差异。本次均值最大绝对差约 6.56×10⁻⁷，标准差约 7.45×10⁻⁸；参数来源仍是同一训练集，不能把这个分支误写成使用 val 拟合。
